## 二、產品賣點表（給作業 3 Part A（文案＋AI 素材）用）

| 項目 | 內容 |
|------|------|
| 產品名稱 | 三重玻尿酸保濕精華 |
| 售價 | NT$1,280 / 30ml |
| 客人最常見的購買原因 | 換季/冷氣房乾到脫皮、上妝卡粉 |
| 用了之後最明顯的改變 | 3 天有感，早上起來臉不緊繃、上妝服貼不卡粉 |

| 成分關鍵字 | 三重玻尿酸、B5、神經醯胺、無香料無酒精 |
