# 作業 4｜優化分析報告
`選做作業 ｜ 模擬數據（有真數據更好）｜ 對應 M7 第 1、4 集 ｜ 建議在 M7–M8 後完成`

**目標**：從數字看出問題，提出具體優化方案，並設計下一輪「只改一個變數」的乾淨測試。

**預估時間**：3.5–5 小時。

**繳交內容**
1. 拿模擬數據包（`dataset-02` / `03` / `04`，或自己的真實數據）。
2. 解讀 CPM/CTR/CPC/CPA/ROAS，找出 **≥1 個問題點**。
3. 提出具體優化動作（換素材 / 調受眾 / 改預算 / 改事件）。
4. 填「優化記錄模板」，並在 Google Sheets 建自己的數據紀錄表。
5. **報告最後一節「下一步測試計畫」（A/B 測試設計）**：
   - 針對一個變數（素材 A vs B，或受眾 A vs B）設計測試。
   - 填測試設計範本：假設、對照組、預算、跑幾天、看哪個指標、判斷標準。
   - 用模擬 A/B 數據（`dataset-05`）練綠勾/灰色判定。
   > 先完成前面的診斷段再寫測試計畫——先會診斷，再設計測試；判定練習用的是獨立的 `dataset-05`。

**兩種學員路徑**
- 有真實產品：優先用自己帳號的真實數據做診斷（在作業 3 Part B 有實際發布者尤其建議）；測試計畫可直接針對自己正在跑（或 Part B 建好）的廣告設計下一輪測試。流程與繳交物相同。
- 沒有產品：模擬數據包讓人人可交；測試計畫純設計 + 模擬數據判讀。

**雲端工具**：模擬數據 CSV ＋ Google Sheets / Data Studio ＋ Google Docs。

**評分重點**：能從數字看出問題、優化方案具體可執行；測試計畫單一變數、假設與判斷標準明確。

**常見踩坑**：只貼數據不分析；優化建議空泛（「素材要更好」）；一次改太多變數無法歸因；樣本不足就下結論。

**繳交格式**：一份優化報告（數據 + 診斷 + 優化動作 + 最後一節「下一步測試計畫」，含對 dataset-05 的判定結論）。

## 數據設定

數據 02、04：品牌 A，銷售目標，目標 CPA 為 TWD 400，目標 ROAS 為 3.0。
數據 03：品牌 B 的獨立練習活動，銷售目標、Purchase 最佳化事件、目標 CPA 為 TWD 1,500；請依資料評估設定，與策略作業的名單目標情境不同。
數據 05：品牌 A，同受眾、同預算，僅比較痛點與成分兩種素材，各組日預算 TWD 2,500。依課堂判斷標準自行分析，不提供判定結論。

CSV 從欄位列開始，可直接匯入 Google Sheets。「—」表示無法計算，非零；小計列請勿重複加總。
