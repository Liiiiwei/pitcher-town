# 作業 3｜素材製作與廣告上線
`選做作業 ｜ 素材需免費帳號；廣告草稿不發布＝零花費 ｜ 對應 M5–M6 ｜ 建議在 M5–M6 後完成`

> **本作業分三個 Part，合計預估 8.5–11.5 小時。** M5、M6 同一天開放，到建議完成日大約 8 天，建議這樣排：
> - 第 1–4 天：Part A（文案與素材）
> - 第 5–6 天：Part B（廣告草稿）
> - 第 7–8 天：在小鎮交作業 3，並勾選公開到展示牆
> - 交完之後一週內：Part C（看展示牆上 2 份同學作品，到 LINE 學員群回饋）

#### Part A｜六角度文案 + AI 素材（對應 M5 第 1、3 集，預估 5–7 小時）

**目標**：同一產品寫出 6 種「真的不同」的說服角度，並用 AI 加速產素材、建立自己的 prompt 模板庫。

**繳交內容**
1. 選模擬品牌一個產品，寫 **6 個切入角度**。可以直接用品牌包「素材製作需求說明」列的 6 個角度，也可以換成自己想的（例如功能、情感、社會認同、急迫、損失、好奇），只要 6 個真的不同就好。**參考你在小練習 1 拆解出的同業角度，避開同質化**。
2. 每個角度一版文案，用 Hook → 痛點 → 方案 → CTA 四段結構。
3. 標好版位規格（1:1 Feed、9:16 Reels）與 CTA 按鈕。
4. 跑「文案檢查清單」自評。
5. 用講義 prompt 框架，在任一 AI 工具生成：文案 3 版 + 圖 3 張。
6. 影片擇一繳交：**AI 生成影片 1 支**，或（工具免費額度不足時）**15 秒影片分鏡腳本＋首幀圖 1 張**。
7. 用 Canva 後製把中文字加上去（圖片生成時留白避免亂碼）。
8. 依 M5 第 3 集的品質把關表自查：背景合理、手機上看得清楚、品牌一致。
9. 整理成自己的 prompt 模板庫（記錄哪個 prompt 效果好）。

> 主流 AI 生成工具多需**註冊免費帳號**、免費額度有限（影片尤其少）——不需為本作業付費，額度不足就交分鏡腳本版。Meta 後台 GEM／Manus AI 台灣未開放，僅課堂示範，不列入交件。

**兩種學員路徑**
- 有真實產品：直接寫自己產品的 6 角度文案（成品就是你的素材庫），並用自己的產品圖走 M5 第 3 集的速成流程（背景生成、圖片擴展、靜態轉影片）。
- 沒有產品：文案全零成本純文字，套模擬品牌賣點表；AI 素材用模擬品牌包附的產品圖 prompt 生成。

**雲端工具**：Google Docs / Canva（免費版）＋ 任一 AI 生成工具（web，免費帳號）。

**評分重點**：6 個角度是否真的不同（不是同一句改字）、文案結構完整；prompt 是否具體、AI 素材是否可用（AI 起頭、人工收尾——Hook 與 CTA 一定要自己改）。

**常見踩坑**：6 個角度其實都在講「效果」；CTA 跟內容對不上；直接用 AI 亂碼文字；prompt 太抽象；為湊影片數量付費買額度。

**繳交格式**：一份文案表（6 角度 × 文案 + 規格）+ 素材成品（含影片或分鏡腳本）+ prompt 模板庫（文件）。

#### Part B｜廣告草稿建立（對應 M6 第 1、2 集，預估 2–3 小時）

**目標**：在你作業 1 建好的模擬品牌廣告帳號裡，走完「活動 → 組合 → 廣告」三層建立流程，最後存成草稿。**全程不發布、零花費**。

> **前置檢查**：需先完成**作業 1**（有可用的廣告帳號）；並依**作業 2** 的目標與受眾規劃、用 **Part A** 的素材。

**繳交內容**（截圖三層）
1. **活動層**：選你在作業 2 決定的廣告目標。
2. **組合層**：依作業 2 的受眾規劃在草稿中建立 Advantage+ 受眾（中文介面叫「高效速成+ 受眾」；地區/年齡/興趣當「提示」）、設日預算、**版位用「自動版位」（含 Threads 預設留著，讓系統自動分配）**。
3. **廣告層**：用 Flexible Ad Format（一則廣告放多張圖、多版文案，讓系統自動配對）上 Part A 的素材和文案、貼落地頁網址並加上 UTM（寫法見下方「網址與 UTM 怎麼寫」），**用「網址與 UTM 自查」檢查**。
4. 三層都照下方「命名規則」取名。
5. **存成草稿、不發布**，跑「發布前七項自查」。

> **Pixel Helper 檢查**：模擬品牌沒有網站，不用做這一項（作業 1 已在真實購物網站看過綠勾）。**有真實網站者**才需要對自己的落地頁跑 Pixel Helper 並附截圖。

**兩種學員路徑**
- 有真實產品：同樣步驟做在自己的帳號；**可選擇實際發布（小額日預算）**，繳交物相同（三層截圖＋清單）。
- 沒有產品：草稿模式走完流程＝零花費（這是「沒客戶也能上機」的核心 Part）。

**雲端工具**：Meta 廣告管理員（草稿）。

**評分重點**：三層結構正確、命名照規則、**版位維持自動**、受眾用「給訊號」而非細疊、UTM 齊全。

**常見踩坑**：一組塞超過 5 則廣告；**手動關掉版位（含 Threads）限制系統分配**；沒加 UTM。

**繳交格式**：三層結構截圖 + 落地頁網址（含 UTM）+ 發布前七項自查打勾。

#### Part C｜素材互評（對應 M5/M6，預估 1–1.5 小時）

**目標**：能評別人 = 真的看懂了。

**怎麼做**
1. 交作業 3 時，在小鎮作業 3 頁面下方的「公開到展示牆」勾選公開（Part A、Part B 各自勾）。講師核可後，作品才會出現在展示牆。
2. 到小鎮「公會 → 展示牆」，點「A3」篩選，挑 **2 份**同學的作品打開來看。本期同學的作品不夠時，可以看學長姐的。
3. 到 LINE 學員群，每份作品各發一則回饋，照下方「互評回饋格式」寫。

**規則**：每題都要寫到具體的地方（哪個角度、哪一句、哪張圖），建議要能照著改。

**兩種學員路徑**
- 有真實產品／沒有產品：無差別——互評的是同學的產出，純評論零成本。

**評分重點**：建議是否具體可執行（「標題加數字製造急迫」而非「文案要更好」）。

**常見踩坑**：只寫「很好」「不錯」。

**繳交格式**：不用在小鎮交，2 則回饋發在 LINE 學員群就算完成。

## 網址與 UTM 怎麼寫

UTM 是接在網址後面的幾個標籤，之後在 GA4 就看得出這個人是從哪個廣告活動、哪一則廣告點進來的。

在廣告層有兩個欄位要填：

1. **網址**：填落地頁網址。模擬品牌沒有真的網站，填品牌包的示意網址就好（例如品牌 A 填 `https://purelab-demo.tw`），草稿不發布，網址打不開也沒關係。
2. **網址參數**：每一則廣告都貼同一串（這串照抄，不要改）：

```
utm_source=facebook&utm_medium=paid_social&utm_campaign={{campaign.name}}&utm_content={{ad.name}}
```

| 參數 | 意思 | 本課規則 |
|---|---|---|
| utm_source | 從哪個平台來 | 一律 `facebook`，全小寫 |
| utm_medium | 哪一種流量 | 一律 `paid_social`，全小寫 |
| utm_campaign | 哪一個廣告活動 | 填 `{{campaign.name}}`，系統會自動換成你的廣告活動名稱 |
| utm_content | 哪一則廣告 | 填 `{{ad.name}}`，系統會自動換成你的廣告名稱 |

「命名一致」的意思是：每則廣告的 source、medium 拼法都一樣，活動和廣告名稱照上面的命名規則取，UTM 裡帶出來的名稱就會跟廣告管理員裡看到的一樣。

點擊後，完整網址會長這樣（以品牌 A 為例）：

```
https://purelab-demo.tw/?utm_source=facebook&utm_medium=paid_social&utm_campaign=CVR_保濕精華_202612&utm_content=單圖_痛點_v1
```

選品牌 C 好初早午餐、廣告目標選互動或訊息的人：這種廣告不會導到網站，網址和 UTM 兩項寫「訊息廣告，不適用」即可。選流量目標導到網站的，網址填 `https://goodmorning-demo.tw`，一樣加上面那串網址參數。
