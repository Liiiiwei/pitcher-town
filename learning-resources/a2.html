作業 2｜廣告策略規劃表

選做作業 ｜ 零成本 ｜ 對應 M4 全模組（受眾段對應 M4 第 3 集）｜ 建議在 M4 後完成

和一對一的關係：作業 1～4 都是選做，但想預約第 1 輪一對一（本期 11/23–12/6），要先在小鎮交出作業 2。講師如果標記你的作業缺東西，補交後才能預約。預約時間看小鎮廣場的「一對一」分頁。

目標：目標、預算、受眾三者邏輯一致的一份完整策略；受眾用 2026 的「給訊號」思維設計（不是回到舊的「後台選人」）。

預估時間：4.5–6 小時。

繳交內容

1. 目標：用決策樹選（知名度/流量/互動/名單/銷售）+ 說明為什麼。

2. 預算：用公式算測試預算（目標 CPA × 50 ÷ 天數）+ 日/月分配。

3. 受眾定向（冷暖熱三層）：

- 冷受眾：規劃 1 組 Advantage+ 受眾（中文介面叫「高效速成+ 受眾」），只給「粗略訊號」（地區/年齡/1–2 個大興趣），並寫明為什麼不再細疊興趣。

- 暖/熱受眾：規劃自訂受眾（互動、影片觀看 25/75%、加購未購、網站訪客）+ 類似受眾 1 組 + 再行銷邏輯。

- 三層對應素材：冷 → 暖 → 熱，每一層寫明「該用什麼素材角度」，實踐「素材就是定向」。

> 名詞小抄：「影片觀看 25/75%」是看過影片至少 25% 或 75% 的人，看到 75% 的意願比較高；「加購未購」是把商品加入購物車但沒結帳的人；「類似受眾」是 Meta 依你給的名單（例如買過的客人）去找特徵相近的新的人；「學習階段」是新廣告組合剛開始、系統還在摸索要投給誰的期間，成效比較不穩，一週累積約 50 筆轉換才會結束。

> 後台實際建立受眾留到作業 3 Part B 一起做——「受眾後台操作」M6 第 1 集才教，本作業排在 M4 後尚未學到。

4. 漏斗圖：品牌 A、品牌 B 各畫一張冷 → 暖 → 熱的廣告架構（模板第 3 部分各有一格）。

5. Advantage+ 決策：三槓桿（受眾/版位/預算）各開或關 + 理由。

兩種學員路徑

- 有真實產品：直接為自己的品牌做這份策略表（用真實客單價與目標 CPA 算預算；受眾用既有資產如粉專互動、網站訪客規劃），做完可直接投、作業 3 Part B 可直接建。

- 沒有產品：套模擬品牌，紙上完成，零成本。

雲端工具：Google Sheets / Docs + 任一畫圖工具。

評分重點：目標 ↔ 預算 ↔ 受眾三者是否一致（例：預算太低卻設轉換目標＝矛盾）；是否用「給訊號 + 素材選人」思維（不是研究幾百個興趣組合）；三層與素材角度對應合理。

常見踩坑：受眾太廣沒分層；漏斗只有單層沒再行銷；還在細疊興趣、把受眾掐死；把預算拆成 5 個受眾群讓 AI 學不動。

繳交格式：一份策略表（含受眾定向三層與素材對應）+ 品牌 A、B 各一張漏斗圖。

教材使用方式

點本頁最下方「瀏覽策略模板」，把內容複製到自己的 Google 文件填寫，漏斗圖貼在同一份文件裡。最後把文件權限改成「知道連結的人 → 檢視者」，連結貼回投手小鎮本作業頁繳交。

所有品牌、數據與情境皆為教學模擬，不含真實學員資料。

作答順序與品牌情境

先替純粹肌研與職涯加速器完成模板第 1–3 部分，再做第 4 部分的自己的品牌策略。

第 4 部分沒有自己品牌的人，三選一：

- 選品牌 A：沿用第 1–3 部分品牌 A 的答案，寫出你會做的三項調整。

- 選品牌 B：沿用第 1–3 部分品牌 B 的答案，寫出你會做的三項調整。

- 選品牌 C 好初早午餐：第 4 部分直接替品牌 C 從頭填一份（月預算在品牌 C 資料裡；目標用加 LINE 好友成本 NT$40 算，不用客單價算 CPA），不用寫三項調整。

作業 3 打算用哪個品牌，這裡就選同一個，前後比較連得起來。

品牌 A：三重玻尿酸保濕精華 30ml，單價與單品客單價均為 TWD 1,280，毛利率約 45%（已扣進貨、物流與平台抽成），月預算 TWD 30,000，IG 粉絲 3,500，過去三個月 120 筆訂單，已有 Pixel 與標準事件。

品牌 B：30 天轉職作品集實戰班，售價 TWD 5,980，先以免費說明會與履歷健檢表收名單，再轉報名；月預算 TWD 25,000。毛利率與名單成交率請自行估算並註明依據。
